# Money Transfer Mini-System

## Описание

Простая система денежных переводов между пользователями.

В этом проекте мы работали со мапами, структурами, каналами,
горутинами, структурами, слайсами, Mutex и WaitGroup.

## Запуск

Установливаем зависимости:

```bash
go mod tidy
```

Запускаем программу:

```bash
go run main.go
```


## Части проекта

### v1

что было сделано:

- структура `User` в отдельном файле;
- методы `Deposit` и `Withdraw`;
- создание пользователей;
- изменение баланса(транзакция между пользователями).

### v2

Что было сделано:

- структура `Transaction` и `PaymentSystem` в отдельном файле;
- сохранение пользователей в `map`;
- очередь транзакций;
- последовательная обработка переводов.

### v3

Что было сделано:

- добавлен канал для передачи транзакций между горутинами;
- реализована работа нескольких воркеров;
- использованы горутины для параллельной обработки;
- добавлен `sync.WaitGroup` для ожидания завершения всех горутин;
- обработка переводов стала выполняться одновременно.

### v4

Что было сделано:

- в структуру `User` добавлен `sync.Mutex`;
- операции пополнения и снятия баланса защищены блокировкой;
- исключена возможность одновременного изменения баланса разными горутинами.
